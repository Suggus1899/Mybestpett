# 🐾 Mybestpett

### Petbf — Todo para tu mascota, en un solo lugar

Tienda en línea de **un solo vendedor** para Venezuela: productos para mascotas, venta de animales y adopción. El cliente se registra, compra y paga en bolívares, euros, dólares o USDT, y un equipo de seis personas verifica los pagos, despacha los pedidos y gestiona el catálogo desde un panel web.

## 📐 Arquitectura

```
   ┌──────────────────────────────┐      ┌──────────────────────────────┐
   │  Web · Next.js (port 3000)   │      │  App móvil · Flutter         │
   │  tienda + panel del equipo   │      │  (fase posterior)            │
   │  cookies httpOnly            │      │  almacenamiento seguro       │
   └──────────────┬───────────────┘      └──────────────┬───────────────┘
                  │            HTTPS · /v1               │
                  └──────────────────┬───────────────────┘
                                     │
                  ┌──────────────────▼───────────────────┐
                  │  API · NestJS (port 3001)            │
                  │  auth · roles · catálogo · inventario│
                  │  tasas BCV · auditoría               │
                  └──────────────────┬───────────────────┘
                                     │ Prisma
                  ┌──────────────────▼───────────────────┐
                  │  PostgreSQL 16                       │
                  └──────────────────────────────────────┘
```

Web y móvil comparten una sola API. Los permisos se comprueban siempre en la API, nunca solo ocultando botones.

## 🚀 Quick Start

### Prerrequisitos

| Herramienta | Versión | Instalación |
|-------------|---------|-------------|
| Node.js | 22+ | [nodejs.org](https://nodejs.org/) |
| pnpm | 10.28+ | `corepack enable` |
| Docker | reciente | [docker.com](https://www.docker.com/) (para PostgreSQL local) |

### 1. Dependencias y base de datos

```bash
pnpm install
pnpm db:up          # PostgreSQL 16 en Docker
```

### 2. Variables de entorno

```bash
cp apps/api/.env.example apps/api/.env          # cambia JWT_ACCESS_SECRET
cp apps/web/.env.example apps/web/.env.local
```

Ver la sección [🔧 Variables de Entorno](#-variables-de-entorno).

### 3. Migraciones y datos iniciales

```bash
pnpm db:migrate     # crea las tablas
pnpm db:seed        # administrador y categorías base
# SEED_DEMO=true pnpm db:seed  → añade productos, animales y una tasa de ejemplo
```

### 4. Desarrollo

```bash
pnpm dev
# ✅ Web en http://localhost:3000
# ✅ API en http://localhost:3001/v1/health
```

### 5. Build de producción

```bash
pnpm build
docker build -f apps/api/Dockerfile -t petbf-api .   # la etapa `migrate` aplica migraciones
```

## 📊 Reglas de Negocio

### Monedas y precios

| Moneda | Cómo se calcula | Métodos de pago |
|--------|-----------------|-----------------|
| USD | Precio base, guardado en céntimos enteros | Zelle, efectivo |
| Bs | USD × tasa BCV del día | Pago Móvil, transferencia |
| EUR | USD × tasa BCV del dólar ÷ tasa BCV del euro | Transferencia en euros |
| USDT | 1:1 con el dólar | Cripto |

- El administrador carga la tasa del BCV cada día hábil. Cada pedido congela la tasa con la que se cobró.
- Los pagos se reportan y el equipo los verifica contra el banco, Zelle o la billetera.
- El cliente tiene **2 horas** para reportar el pago; si no, el pedido se cancela y el stock vuelve.
- Una referencia de pago no puede pagar dos pedidos.

### Envíos y devoluciones

- Envío **gratis desde 25 $**; por debajo se cobra una tarifa por zona.
- Devoluciones en un máximo de **3 días** desde la entrega.
- El alimento abierto y los productos de higiene abiertos no se devuelven.

### Roles del equipo

Una persona puede tener varios roles a la vez.

| Rol | Qué hace |
|-----|----------|
| `CUSTOMER` | Cliente registrado; comprar exige cuenta |
| `ADMIN` | Acceso total: cuentas, roles y tasas |
| `ORDERS_OPERATOR` | Verifica pagos, prepara y despacha pedidos |
| `CATALOG_MANAGER` | Productos, precios, stock y animales en venta |
| `ADOPTION_COORDINATOR` | Fichas de adopción y solicitudes |

## 🔧 Variables de Entorno

### API (`apps/api/.env`)

| Variable | Requerida | Default | Descripción |
|----------|-----------|---------|-------------|
| `DATABASE_URL` | ✅ | — | Connection string de PostgreSQL |
| `JWT_ACCESS_SECRET` | ✅ | — | Secreto para firmar el access token (mínimo 32 caracteres) |
| `PORT` | ❌ | `3001` | Puerto de la API |
| `CORS_ORIGINS` | ✅ prod | — | Orígenes permitidos, separados por coma |
| `JWT_ACCESS_TTL_SECONDS` | ❌ | `900` | Duración del access token |
| `REFRESH_TOKEN_TTL_DAYS` | ❌ | `30` | Duración de la sesión |
| `AUTH_THROTTLE_LIMIT` | ❌ | `10` | Intentos por minuto en registro y login |
| `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` | ❌ | — | Cuenta de administrador que crea el seed (contraseña de 12+ caracteres) |
| `SEED_DEMO` | ❌ | `false` | Añade datos de ejemplo; no se permite en producción |

### Web (`apps/web/.env.local`)

| Variable | Requerida | Default | Descripción |
|----------|-----------|---------|-------------|
| `API_URL` | ✅ | — | URL de la API; solo la usa el servidor de Next, nunca el navegador |

### Ejemplo `.env`

```env
# API
DATABASE_URL=postgresql://petbf:petbf@localhost:5432/petbf?schema=public
JWT_ACCESS_SECRET=cambia-esto-por-un-secreto-largo-y-aleatorio
CORS_ORIGINS=http://localhost:3000

# Web
API_URL=http://localhost:3001/v1
```

## 🧪 Testing & CI

```bash
pnpm typecheck                  # tipos en todo el monorepo
pnpm lint                       # lint en todo el monorepo
pnpm test                       # pruebas unitarias
pnpm --filter api test:e2e      # e2e de la API contra una base desechable (ver apps/api/README.md)
pnpm --filter web test:e2e      # Playwright: necesita pnpm build y SEED_DEMO=true pnpm db:seed
```

Las pruebas cubren los casos válidos, las validaciones y los intentos de abuso, tanto del cliente como del panel.

### CI Pipeline (GitHub Actions)

| Paso | Descripción |
|------|-------------|
| **Calidad** | Install → Typecheck → Lint → Test unitarias |
| **API** | Migraciones sobre PostgreSQL 16 → pruebas e2e |
| **Web** | Build → seed de ejemplo → Playwright (cliente y panel) |
